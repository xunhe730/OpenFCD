# Ralph Progress Log — feat/fcd-scale-registration

## Session: 2026-04-24

### Root Cause (discovered via investigation)
FCD fails on 4.21-expt/10-1 dataset because reference frames (7091-7098) have
carrier period ~60px and experimental frames (7197-7214) have ~52px — a 14% 
scale mismatch from camera zoom change between sessions. FCD assumes identical
carrier frequency in ref and def; mismatch causes algorithm to output checkerboard
pattern instead of surface height.

Secondary issue: flatfield_sigma=300 is fixed regardless of image dimensions;
inadequate for 5568×3712 images where proper sigma should be ~334.

### Implementation

US-001: openfcd/core/registration.py
- scale_normalize_reference(ref_ff, def_ff, carriers_ref, tolerance=0.03)
- Returns (aligned_ref_ff, aligned_carriers, scale)
- No-op when |scale-1| < 3%; warns at 10%+
- Crops center when scale>1, pads with mean when scale<1
- Graceful fallback if def carrier detection fails

US-002: cmd_run.py integration

- Conditioned on getattr(project.process, "auto_scale_ref", True)

- ProcessConfig gains flatfield_sigma_auto:bool=True, auto_scale_ref:bool=True
